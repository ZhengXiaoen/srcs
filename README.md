# 散人传说单机修改

先启动 phpStudy，再使用根目录的一键启动、停止入口管理游戏服务器。

| 文档 | 用途 |
| --- | --- |
| [游戏时间](GameClock.使用说明.md) | 启停、时间模式与异常恢复 |
| [物品数量扩容](物品数量扩容补丁.使用说明.md) | 9999 堆叠的使用、检查与回滚 |
| [外观合成](Server/S1001/data/functions/AppearanceMake.说明.md) | 坐骑、足迹、时装三合一与堆叠穿戴 |
| [常驻功能开放](Server/S1001/data/functions/合服功能开放说明.md) | 饰品、玫瑰、转职及转性的开放条件 |
| [修改大全](修改大全.md) | 主要功能调整 |
| [项目约定](AGENTS.md) | 修改范围、验证、文档与 Git 提交要求 |

维护脚本与回归检查位于 `tools/`。漏捡现场可用 `tools/monitor_drop_pickup.py` 限时只读采样，参数见 `--help`；需提供当前逻辑服 PID、角色名及不存在的输出文件。未知服务器版本会拒绝采样，记录不能替代客户端状态及拾取请求验证。
