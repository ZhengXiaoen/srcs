# BOSS 材料掉落与金币调整

普通材料已在 `bd273ee` 撤回 `d5a72c8` 的整组掉落改造：154 个原掉落模板恢复391条材料记录，由服务器原生掉落流程处理。重复记录不再合并，后续大面额替换仍直接维护原生掉落记录。

`BossMaterialDropCfg.lua`、材料汇总函数、对应日志 ID 和整组掉落专用测试已移除。后续材料奖励直接维护原掉落模板。

## BOSS 材料面额替换

50 个掉落模板中的69条高数量奖励改为等值的大面额材料，涉及203种BOSS：护盾碎片49条、护符碎片10条、神魂10条。概率、绑定、拾取保护和其他掉落条件保持不变，材料总值不变。

例如护盾碎片(100)（ID 568）×30改为护盾碎片(1000)（ID 569）×3；护盾碎片(1000)×12改为护盾碎片(10000)（ID 570）×1加护盾碎片(1000)×2；神魂(10)（ID 5165）×10改为神魂(100)（ID 5166）×1；护符碎片(1000)（ID 535）×12改为护符碎片(10000)（ID 536）×1加护符碎片(1000)×2。

仅调整固定数量的奖励，不合并不同掉落记录或概率分组。带余数的拆分仅适用于必掉且不属于概率分组的记录。普通神魂（ID 5171）因拾取分类不同保持原样；宝石结晶、圣珠结晶等未找到需要替换的高数量记录。

怪物545与BOSS共用 `drops1511.lua`，现改为引用内容与替换前完全相同的 `drops1511Normal.lua`，普通怪奖励保持不变。客户端已有对应大面额道具，其名称、使用价值、自动使用支持及已打包资源与服务端一致，掉落显示使用服务端传来的道具ID和数量，无需修改客户端资源。

## 真荒古灵力丹

怪物635在地图286被击杀时，仍必掉战将灵力丹(中)（ID 552）共3–5个；30%概率掉战将灵力丹(大)（ID 553）共1–2个。每个灵力丹独立创建为数量1的地面物品，保留非绑定状态及宠物、战将击杀支持。

地图入口提示、荒古传送卷的前后端说明仍与上述数量、概率一致，奖励内容未变。

## 金币掉落

所有怪物掉落模板继续移除金币和绑定金币。原来掉金币的582种BOSS各掉落1个商城同款金砖(绑金)（ID 508，商城售价300元宝，使用获得60万绑定金币）；普通怪不增加金砖。

原有10秒拾取保护的5种BOSS继续使用 `dropsBossGoldBrickProtected.lua`，其余使用 `dropsBossGoldBrick.lua`。金砖引用、单件数量和“其他道具”自动拾取范围保持当前配置。

本次未重启服务器、未做额外运行测试。服务器脚本在下次正常重启后加载；客户端已有材料和金砖资源，地面数量由掉落协议提供，无需改动资源包。
