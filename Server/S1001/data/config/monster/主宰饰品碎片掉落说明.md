# 转生神殿主宰饰品碎片掉落

合服后，天、地、暗三类 BOSS 使用相同的独立掉落概率，不再与装备争用概率分组。每次成功掉落时，从面甲、护肩、吊坠、护膝碎片（5152–5155）等概率选一种，以配置数量创建一件绑定地面物品。主宰饰品成品不增加直接掉落。

| 转生等级 | 掉出任意一种碎片的概率 | 每次数量 |
|---|---:|---:|
| 1转 | 10% | 1个 |
| 2转 | 20% | 1个 |
| 3转 | 30% | 1个 |
| 4转 | 40% | 1–2个 |
| 5转 | 50% | 1–2个 |
| 6转 | 60% | 1–2个 |
| 7–8转 | 70% | 2个 |
| 9–10转 | 80% | 2个 |
| 11–12转 | 90% | 2–3个 |
| 13–15转 | 100% | 2–3个 |

概率以 BOSS 所属神殿档次为准，不按击杀角色的转生等级计算。只在地图287–296中对各档配置的三个 BOSS 生效，支持玩家、宠物及战将击杀。未合服时不掉落，指定一种碎片的概率为总掉率的四分之一。

配置集中在 `ZhuanShengAccessoryDropCfg.lua`，由 `MonsterFunction.lua` 的击杀回调处理。原 `drops2190.lua`–`drops2197.lua`、`drops2330.lua` 中36条碎片记录已移除，保留其他掉落记录。神殿入口提示读取同一份配置；服务端道具说明、客户端独立道具资源和 `zh-cn.dat` 中对应资源同步更新。

修改需在服务器正常重启或完整重载相关脚本后生效；本次未重启运行中的服务器。

验证：5项自动检查通过，覆盖全部30个BOSS的0–99概率判定边界、四种碎片及数量上下限、合服限制、地图与怪物范围、入口提示和前后端资源一致性。资源包仅修改两份道具目录中四种碎片的说明，其他资源逐项比对保持一致；旧模板除36条碎片记录外字节不变。

怪物合并脚本与完整怪物掉落配置通过Lua 5.1编译检查。全局合并脚本在标准Lua检查中存在修改前即有的语法与局部变量限制问题，已与修改前版本对照；本次辅助函数挂在已有LocalDT上，没有新增顶层局部变量。未进行实际服务器启动或游戏内击杀验证。
