# 转生神殿主宰饰品掉落

开服即可掉落，天、地、暗三类 BOSS 使用相同的独立掉落概率，不再与装备争用概率分组。每次碎片判定成功时，从面甲、护肩、吊坠、护膝碎片（5152–5155）等概率选一种，以配置数量创建一件绑定地面物品。

7转及以上神殿另有独立成品判定，与原碎片掉落互不影响，同一次击杀可以同时掉落碎片和成品。成品判定成功后，从主宰吊坠、护肩、面甲、护膝（5140–5143）等概率选一种，掉落1件绑定成品。概率指掉出任意一种成品，指定一种成品的概率为总掉率的四分之一。1–6转不增加成品掉落。

| 转生等级 | 掉出任意一种成品的概率 | 每次数量 |
|---|---:|---:|
| 7–8转 | 5% | 1件 |
| 9–10转 | 7% | 1件 |
| 11–12转 | 11% | 1件 |
| 13–15转 | 15% | 1件 |

原碎片概率与数量保持不变：

| 转生等级 | 掉出任意一种碎片的概率 | 每次数量 |
|---|---:|---:|
| 1转 | 10% | 1个 |
| 2转 | 20% | 1个 |
| 3转 | 30% | 1个 |
| 4转 | 40% | 1–2个 |
| 5转 | 50% | 1–2个 |
| 6转 | 60% | 1–2个 |
| 7–8转 | 70% | 2个 |
| 9–10转 | 80% | 2个 |
| 11–12转 | 90% | 2–3个 |
| 13–15转 | 100% | 2–3个 |

概率以 BOSS 所属神殿档次为准，不按击杀角色的转生等级计算。只在地图287–296中对各档配置的三个 BOSS 生效，支持玩家、宠物及战将击杀。无需配置合服日期，指定一种碎片的概率为总掉率的四分之一。

配置集中在 `ZhuanShengAccessoryDropCfg.lua`，由 `MonsterFunction.lua` 的击杀回调处理。`rate/mincount/maxcount`控制碎片；`finishedRate`控制成品，每次1件。辅助函数均挂在已有`LocalDT`表上，不增加顶层局部变量。原 `drops2190.lua`–`drops2197.lua`、`drops2330.lua` 中36条碎片记录已移除，保留其他掉落记录。神殿入口仅展示进入条件和刷新时间，道具说明不额外展示掉落概率。详细规则保留在本配置文档中。

修改需在服务器正常重启或完整重载相关脚本后生效；本次未重启运行中的服务器。

自动检查覆盖全部30个BOSS的概率边界、四种碎片和成品ID、数量与绑定、1–6转无成品、地图和怪物范围、玩家/宠物/战将击杀、无合服要求、入口提示及前后端资源一致性。对四档高阶神殿穷举碎片与成品两次0–99判定的40,000种组合，确认两种掉落独立；碎片创建失败不影响成品判定。13–15转碎片仍为100%，每次2–3个。

清理额外展示文案后，`tools/test_zhuansheng_accessory_drop.py`校验客户端独立资源与`zh-cn.dat`一致，并确认只修改指定道具描述与任务文字，道具ID、数量、图标及其他字段保持不变。
