# 坐骑堆叠使用与外观三合一

坐骑、足迹、三国时装按神盾样式点击三合一：消耗三个相同道具，获得一个高一级道具，无需拆分。共 57 条配方（坐骑 18、足迹 24、时装 15）；优先用绑定材料，使用绑定材料时成品绑定，失败返还已扣材料。

分类页分别列出坐骑 6、足迹 8、时装 5 个系列，无分页；系列内显示三条升级配方及物品链接。合成成功留在详情页，“返回主页”回到分类页；旧按钮及分页入口兼容。

堆叠坐骑穿戴只扣一个，失败按原逻辑返还，保留背包余量；等级、交易、替换、属性及协议通知继续遵循原规则。

## 生效

- 停服后使用根目录“一键启动”，客户端重新登录加载 `GameFrame.swf`、`Mount.swf` 和语言包，必要时清理缓存。
- 9999 数量扩容已包含坐骑补丁，启动时检查扩容配套清单，详见根目录的物品数量扩容说明。
- 未使用扩容清单时，`GameClock.ps1` 按 `Server/S1001/x64/mount-stack.patch.json` 校验并安装旧版坐骑补丁，保留 `.before-mount-stack.bak`；已安装版本不重复修改，不支持的版本中止启动。
- 手动维护旧版补丁可在停服时运行 `tools/patch_mount_stack_native.py`，依赖 `pefile`、`keystone-engine`；`--check` 只检查安装情况。

## 维护检查

- `tools/test_appearance_upgrade.py`：全部配方、绑定、失败返还、旧协议及前后端资源一致性。
- `tools/test_mount_stack_native.py`：实际补丁指令及模拟接口下的扣除、返还、属性和通知。
- `tools/Test-MountStackPatch.ps1`：安装、备份、幂等、运行保护与版本校验。

这些检查不能替代真实角色合成、穿戴和重登验证。修改 Lua 后仍须按项目约定验证完整 `GlobalFunction.lua` 合并编译。
