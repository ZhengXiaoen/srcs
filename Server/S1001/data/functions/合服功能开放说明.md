# 常驻功能合服条件检查与开放

本次按“只开放常驻功能；原合服第 N 天改为开服第 N 天”的规则处理。

| 功能 | 原判断或问题 | 修改后的行为 |
| --- | --- | --- |
| 锻造 → 合成 → 饰品 | 服务端拒绝未合服角色的第 4 类合成请求 | 未合服也可合成主宰、皓月、热血四部位饰品，共 12 条配方 |
| 饰品锤炼 | 服务端要求合服；宝物窗口隐藏饰品；锻造没有加入饰品页 | 直接开放锤炼，锻造恢复“饰品”入口，宝物中的原饰品入口同时开放 |
| 角色饰品栏 | 角色页按钮、饰品格、空槽效果与格子过滤依赖合服 | 未合服也可打开、查看和穿戴饰品 |
| 合成树中标记合服开放的配方 | `openday = -1` 时要求合服 | 直接开放；配方自身的正数开服天数、职业条件仍生效 |
| 玫瑰小姐购买红玫瑰 | 购买菜单只在合服后出现 | 未合服也显示购买菜单，保留副本场景限制 |
| 转职、转性 | 开服第 2 天且合服后需等待到第 6 天 | 统一开服第 6 天开放，保留等级、道具、婚姻和装备条件 |

饰品页复用原 `web/v2/modules/baowu/BaoWu.swf` 中的 `EquipBoostOrnamentPage` 及渲染代码。将现有模块代码合入主客户端，保留原主客户端所有方法编号、名称和非目标方法，未改图像、音效、物品配置或奖励表。锻造常规页签导航保持原索引，旧的饰品特殊导航参数通过实际页面位置定位。
