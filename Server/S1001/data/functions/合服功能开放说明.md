# 常驻功能开放条件

常驻功能取消合服门槛，原合服天数门槛改按开服天数判断。

| 功能 | 当前规则 |
| --- | --- |
| 锻造 → 合成 → 饰品 | 主宰、皓月、热血四部位共 12 条配方，未合服也可合成 |
| 饰品锤炼 | 锻造及宝物入口开放 |
| 角色饰品栏 | 未合服也可查看、穿戴 |
| 合成树 | `openday = -1` 直接开放；正数开服天数及职业条件仍生效 |
| 玫瑰小姐 | 未合服也可购买红玫瑰，保留副本场景限制 |
| 转职、转性 | 开服第 6 天开放，保留等级、道具、婚姻及装备条件 |

饰品页复用 `web/v2/modules/baowu/BaoWu.swf` 的 `EquipBoostOrnamentPage`，常规锻造页签索引及旧特殊导航兼容。

合服登录礼包、返利、双倍经验、王城 BOSS、首届攻城奖励、补偿和重名改名卡仍按真实合服状态；寻宝表、神秘商店刷新及攻城时间也保留合服天数规则。未启用的旧神秘高僧活动不在开放范围内；神殿主宰饰品掉落已取消合服限制。

## 生效与维护检查

服务端重载脚本（GM `@rsf`）或重启后生效；客户端关闭旧页面重新进入，必要时清除缓存。

`tools/test_merge_feature_gates.py` 覆盖 12 条配方、材料/背包不足、锤炼等级、开服第 5/6 天、玫瑰菜单、页签导航、前后端材料及资源包一致性，并检查完整全局脚本编译。实际角色合成、穿戴与锤炼仍需游戏内验证。
